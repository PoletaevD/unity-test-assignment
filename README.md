# Сервис подписок на NetworkMessage для Mirror

Сервис позволяет серверу отправлять сообщения только тем клиентам, которые
явно подписались на соответствующий тип `NetworkMessage`.

## Запуск

1. Откройте сцену `Assets/Scenes/Network Message.unity`.
2. Запустите Play Mode.
3. В стандартном `NetworkDiscoveryHUD` нажмите
   `Start Host` или `Start Server`.
4. Клиент (Host, либо отдельный инстанс приложения через `Find Server`) подпишется на `HelloMessage`, после чего сервер отправит ему
   сообщение `Hello Client!`.
5. Результат будет выведен в консоль.

## Реализация

- `NetworkMessageService` регистрируется в VContainer как singleton.
- Клиентский метод `Subscribe<T>` сначала регистрирует обработчик Mirror, затем
  отправляет серверу ID типа сообщения.
- Сервер хранит подписки отдельно для каждого подключения.
- `TrySend<T>` вызывает стандартный `NetworkConnection.Send` только при наличии
  подписки клиента на тип `T`.
- При отключении клиента его подписки удаляются.
